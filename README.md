# Stock Project

## Genel Bakış
Stock projesi, Java dilinde nesne yönelimli programlama yaklaşımıyla geliştirilmiş bir uygulamadır. Amaç, hisse senedi nesnesi üzerinden fiyat değişimlerini modellemek ve yüzdesel değişimi hesaplamaktır.

## Kullanılan Parametreler
- **symbol**: Hisse senedi sembolü (ör. ORCL).  
- **name**: Hisse senedi adı (ör. Oracle Corporation).  
- **previousClosingPrice**: Önceki kapanış fiyatı.  
- **currentPrice**: Güncel fiyat.  

## Fonksiyonlar
- **getChangePercent()**: Önceki kapanış fiyatı ile güncel fiyat arasındaki yüzdesel değişimi hesaplar.  

## Amaç
- Hisse senedi fiyatlarının değişimini nesne yönelimli yapıda modellemek.  
- Kullanıcıya sembol, isim, önceki kapanış ve güncel fiyat bilgilerini göstermek.  
- Yüzdesel değişimi otomatik hesaplayarak konsolda çıktı vermek.  

## Teknolojiler
- **Java SE**: Programlama dili.  
- **NetBeans IDE**: Geliştirme ortamı.  
- **Git & GitHub**: Versiyon kontrol ve işbirliği.
